# etymology-shorts

A fully-local YouTube Shorts factory. One curated entry per channel per day →
painterly 9:16 video → uploaded to YouTube. No third-party AI APIs;
everything runs on a single Apple Silicon Mac.

**Channels** (each runs the same pipeline against its own queue + prompts):

| Slug | Name | Topic | Queue |
|---|---|---|---|
| `wordstrata` | [Wordstrata](https://youtube.com/@wordstrata) | etymology | 100 words |
| `the-mythscape` | [The Mythscape](https://youtube.com/@TheMythscape) | mythology | 50 myths |
| `open-verdicts` | [Open Verdicts](https://youtube.com/@OpenVerdicts) | historical mysteries | 50 cases |
| `bright-beasts` | [Bright Beasts](https://youtube.com/@BrightBeasts) | animal cognition | 50 findings |

## What it does

For each entry in a channel's queue (`channels/<slug>/words.csv`), the
pipeline produces a 1080×1920 vertical short with:

- **3-beat narration** generated by Ollama (hook → origin → payoff), 90–130 words
- **5–7 painterly images** generated by Z-Image-Turbo (MLX/Apple Silicon)
- **Voiceover** by Piper TTS — one of 4 public-domain voices picked at random per video (Norman, John, Bryce, Joe — all commercial-use-OK)
- **Live sentence-level captions** (TikTok-style, advancing with the voice)
- **Always-on title** (the word in big bold Inter) during narration
- **Branded outro card** (SUBSCRIBE pill + LIKE / SHARE / BELL pills) during the spoken CTA
- **YouTube upload** as private by default; you flip to public after review

Wall-clock per video: ~25 min (image generation dominates). Daily cron via n8n.

## Architecture

```
┌──────────────────────────────────────────────────────────────────────────┐
│ Host (Apple Silicon Mac)                                                 │
│                                                                          │
│  ┌─ Docker / OrbStack ─┐    ┌─ host processes ─────────────────────────┐ │
│  │  n8n :5678          │───▶│  Ollama :11434       gemma4:8B (script)  │ │
│  │                     │───▶│  shorts-api :7860    FastAPI (uvicorn)   │ │
│  │  Daily cron         │    │   ├─ POST /script    → Ollama            │ │
│  │  GET /state/next    │    │   ├─ POST /voice     → Piper TTS         │ │
│  │  POST /script       │    │   ├─ POST /image     → Z-Image-Turbo     │ │
│  │  POST /voice        │    │   ├─ POST /assemble  → ffmpeg + Pillow   │ │
│  │  POST /image        │    │   └─ POST /upload    → YouTube Data API  │ │
│  │  POST /assemble     │    │                                          │ │
│  │  POST /upload       │    │  Storage: SQLite (state.db) + filesystem │ │
│  └─────────────────────┘    └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

n8n in Docker reaches the host via `http://host.docker.internal:7860`.

## Quick start

```bash
# 1. Clone and enter
git clone https://github.com/rushabhpasad/n8n-etymology-shorts.git etymology-shorts
cd etymology-shorts

# 2. Install host tools (one-time)
brew install python@3.12 uv ffmpeg jq

# 3. Install Python deps (creates api/.venv/)
cd api && uv sync && cd ..

# 4. Make sure Ollama is running with the script model
brew install ollama       # or use the .app installer
ollama serve &            # background; defaults to localhost:11434
ollama pull gemma4        # ~5GB; one-time

# 5. Start the FastAPI service
cd api && uv run uvicorn main:app --host 0.0.0.0 --port 7860 &
cd ..

# 6. Initialize each channel's queue
curl -X POST http://localhost:7860/wordstrata/state/init
curl -X POST http://localhost:7860/the-mythscape/state/init
curl -X POST http://localhost:7860/open-verdicts/state/init
curl -X POST http://localhost:7860/bright-beasts/state/init

# 7. (Optional) Run n8n in a container for the daily cron
docker run -d --name n8n -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n:latest

# 8. Generate per-channel n8n workflows, then import each into n8n
python3 n8n/generate.py
# Then in n8n UI (http://localhost:5678): Workflows → Import from File →
# select each n8n/workflows/<slug>.json

# 9. (Optional) Generate channel-icon candidates for each new channel
for slug in the-mythscape open-verdicts bright-beasts; do
  uv run --project api scripts/gen_brand.py --channel $slug
done
# Then pick a favorite from assets/brand/<slug>/ and upload via YouTube
# Studio → Customisation → Branding.
```

## YouTube upload setup (one-time)

```bash
# A. Create an OAuth 2.0 Desktop Client in Google Cloud Console.
#    Enable "YouTube Data API v3". Add your Google account as a Test User.
#    Download the credentials JSON to:
#      secrets/youtube_oauth.json

# B. Each channel needs its OWN OAuth client + token (different YouTube
#    channel → different Google account → different OAuth project). Save the
#    client-secret JSON for each as secrets/youtube_oauth.<slug>.json, then:
mkdir -p secrets
uv run scripts/yt_init.py --channel wordstrata
uv run scripts/yt_init.py --channel the-mythscape
uv run scripts/yt_init.py --channel open-verdicts
uv run scripts/yt_init.py --channel bright-beasts

# C. Each writes secrets/youtube_token.<slug>.json. The service auto-refreshes
#    tokens on every upload — no further manual auth needed.
```

## Trigger a video

All endpoints are scoped by channel — pass the slug in the URL path.

```bash
SLUG=wordstrata            # or the-mythscape / open-verdicts / bright-beasts

curl -X POST -H 'content-type: application/json' \
  -d '{"word_id":1}' http://localhost:7860/${SLUG}/script
curl -X POST -H 'content-type: application/json' \
  -d '{"word_id":1}' http://localhost:7860/${SLUG}/voice
curl -X POST -H 'content-type: application/json' \
  -d '{"word_id":1}' http://localhost:7860/${SLUG}/image      # ~20 min
curl -X POST -H 'content-type: application/json' \
  -d '{"word_id":1}' http://localhost:7860/${SLUG}/assemble
curl -X POST -H 'content-type: application/json' \
  -d '{"word_id":1,"privacy":"public"}' http://localhost:7860/${SLUG}/upload

# Or: trigger the full chain via that channel's n8n workflow.
# Default schedules (staggered to avoid GPU contention):
#   wordstrata     09:00 local
#   the-mythscape  10:00 local
#   open-verdicts  11:00 local
#   bright-beasts  12:00 local
# Tunable in n8n/generate.py (CRON_BY_SLUG).
```

## Migrating an existing single-channel install

If you ran an earlier single-channel (Wordstrata-only) install:

```bash
bash scripts/migrate_to_multichannel.sh   # moves secrets/ + output/ in-place
# then restart uvicorn — state.db migrates itself on startup
```

## Tech stack

| Layer | Choice | License | Notes |
|---|---|---|---|
| Orchestration | **n8n** | Sustainable Use License | Self-hosted in Docker |
| LLM (script gen) | **Ollama `gemma4:latest`** (8B Q4_K_M) | Gemma TOU | Commercial use OK |
| Image gen | **Z-Image-Turbo** (Tongyi-MAI via mflux) | Apache-2.0-ish | Apple Silicon: ~30 s/step × 8 steps × 5 images ≈ 20 min/video |
| TTS | **Piper** — 4-voice random pool: norman, john, bryce, joe | Public domain / CC0 | YouTube-monetization safe; voice shuffled per video for variety |
| Typography | **Inter Bold** | SIL OFL 1.1 | Bundled at `assets/fonts/` |
| Video | **ffmpeg + Pillow overlays** | LGPL + MIT-style | Homebrew ffmpeg lacks libfreetype, so all text is rendered to PNG via Pillow and overlaid |
| Upload | **YouTube Data API v3** | Google API ToS | OAuth Desktop client, refresh token persisted |

## Adding more entries to a channel queue

Each channel ships with a seed `channels/<slug>/words.csv`. To extend any
channel's queue:

```bash
# Wordstrata (etymology — uses Wiktionary verification):
uv run scripts/gen_words.py --channel wordstrata --count 20
uv run scripts/gen_words.py --channel wordstrata --count 20 --append

# The Mythscape, Open Verdicts, Bright Beasts (Wiktionary skipped automatically
# — their subject columns aren't dictionary words):
uv run scripts/gen_words.py --channel the-mythscape --count 10 --append
uv run scripts/gen_words.py --channel open-verdicts --count 10 --append
uv run scripts/gen_words.py --channel bright-beasts --count 10 --append

# Focus on a specific category:
uv run scripts/gen_words.py --channel the-mythscape --count 10 --category norse --append

# Or use any cloud LLM instead: paste channels/<slug>/prompts/words.md into
# the chat, supply your exclusion list, and validate the output yourself.
```

The script auto-detects each channel's CSV schema (subject column varies by
channel: `word` / `figure_or_myth` / `case_name` / `subject_name`), dedups
against existing rows, and assigns the next available `id`. Wiktionary
verification is enabled only for Wordstrata (the only channel where subjects
are dictionary words).

## Channel branding

Each channel has a `channels/<slug>/brand.json` defining its visual identity —
a brand concept, color palette, and 4 distinct icon prompts. Currently shipped
for `the-mythscape`, `open-verdicts`, and `bright-beasts`; `wordstrata` uses a
manually-designed icon. The icon prompts share the painterly oil-on-canvas
style anchor with the video shorts so the channel feels cohesive.

Regenerate icon candidates (1024×1024 PNGs via Z-Image-Turbo / mflux):

```bash
uv run --project api scripts/gen_brand.py --channel <slug>
# Flags: --only <name>, --steps, --seed, --width, --height, --quantize 8
```

Outputs land at `assets/brand/<slug>/icon_<name>.png` — 4 candidates per run.
Each render takes ~30 s on Apple Silicon; ~2 min total per channel. Iterate by
editing `channels/<slug>/brand.json` and re-running. Pick the favorite and
upload via YouTube Studio → Customisation → Branding → Picture.

## State & storage

- **`~/etymology-shorts/state.db`** (SQLite) — words queue + per-upload audit
  trail with model versions, file paths, and YouTube IDs. Single source of
  truth.
- **`~/etymology-shorts/output/`** — `scripts/`, `audio/`, `images/`,
  `videos/`. One file per word.
- **`~/.cache/huggingface/hub/`** — model weights (~15 GB Z-Image-Turbo, ~60 MB per Piper voice × 4).

These paths are configurable in `api/config.py` via `pydantic-settings`
environment variables.
